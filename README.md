I build full-stack web applications with the MERN stack and integrate AI into real, working products — not just tutorials. ## 📖 My Journey

**2023 — The Start**
Began BCA with zero coding background — just curiosity. First lines of code, first "why isn't this working" nights.

**2024 — Foundations**
Learned JavaScript, then React, Node.js, Express, and MongoDB — building small projects to actually understand the stack, not just copy it.

**2025 — Shipping Real Things**
Built and deployed **UrbanNest**, a full hostel booking platform — my first project real users could actually open. Also competed in a 24-hour hackathon along with a few other coding events and competitions.

**2025 — Going Independent**
Started freelancing on Fiverr as an independent developer, taking on real client work.

**2026 — AI Era**
Started building AI-integrated products — **NutriVision** analyzes food photos with the Gemini Vision API. Enrolled in a structured AI/ML developer program, learning Python fundamentals and working toward data analysis and ML roles.

**Now**
Final year of BCA, actively looking for an internship or first full-time role — while continuing to freelance and build in public.
